# 지역별 브리프·기획 단서·PDF 비교

2026-10-06 검증. 2026-10-04 기준으로 저장된 실제 동래점·광화문중앙점 조사와 기존 GPT 검토 결과를 재사용했다. 새로운 Scout/GPT/API 호출은 하지 않았다. 따라서 현재 API 가용성이나 최신 지역 상황을 확인한 결과는 아니다.

## 지역 차이

| 관측 | KT플라자 동래점 | KT플라자 광화문중앙점 |
| --- | --- | --- |
| 매출액 최다 연령 구간 | 60대 이상 58.3% | 20대 36.1% |
| 매출액 최다 요일 | 토요일 27.6% | 금요일 50.2% |
| 유동인구 최다 연령 구간 | 60대 이상 37% | 60대 이상 24% |
| 유동인구 최다 요일 | 목요일 15.1% | 수요일 16.9% |
| 주거인구 | 55,602명 · 2026년 하반기 | 13,941명 · 2026년 하반기 |
| 직장인구 | 47,875명 · 2026년 상반기 | 369,421명 · 2026년 상반기 |

자료 범위는 선택 영역 / 요청 반경 1km이다. 유동·주거·직장 인구와 매출은 별도 집계다. 성별·연령·요일·시간대 역시 각각의 분포이며 교차 고객군이나 특정 요일의 특정 시간대 선호를 확정하지 않는다. 구성비 자료의 기준월이 없는 항목은 추정하지 않았다.

상권·타깃 고객·상품 접점·행사 시기·판촉물 단서의 다섯 항목이 지역별로 달라졌다. 직원 수는 두 지역 모두 조사 자료가 없어 추천 수치를 만들지 않았다. 같은 최다 연령 구간의 반복 문장은 하나로 묶되 모집단별 비율을 유지했다.

전국 행사 참고는 각각 5건이며 3건이 공통, 2건씩 다르다. 전국 사례를 참고하는 목적이므로 공통 사례 자체를 오류로 보지 않는다. 다만 수집 사례가 지역마다 조금 다른 것만으로 성별·연령에 따른 맞춤 검색 효과가 입증되지는 않는다. 그 검증에는 동일 지역·기간에서 고객 맥락만 바꾸는 별도 비교가 필요하다.

## 출력 검증 및 수정

- 웹 JavaScript와 Python 텍스트의 항목별 기획 단서·숨은 기회가 일치한다.
- PDF 5장도 같은 데이터 단서를 사용한다. 이전의 일반적인 기획 조언을 대체했다.
- 지역별 PDF에 수치 11개, 구성비 58개, 기획 단서 동래 12개·광화문 11개가 포함되는지 텍스트 추출로 검사했다. 개별 그래프의 픽셀 길이를 자동 검증한 것은 아니다.
- PDF는 각각 13쪽이다. 페이지 렌더링으로 한글, 줄바꿈, 제목·본문 분리와 잘림을 확인했다. 항목 제목과 해당 단서를 함께 배치한다.
- 실제 화면을 저장 자료로 재생해 매장·주소 전환, 기획 단서와 유동인구/매출액 그래프 전환을 확인했다. 광화문 유동인구 60대 이상과 매출액 20대가 구분된다.
- Python 관련 검사 14개와 웹 기획 단서 Node 검사가 통과했다. 입력 조사 자료는 변경하지 않았다.

## 남은 품질 과제

Quant는 두 저장 결과에서 success, Local·Trend는 partial이다. 광화문 Local의 본문으로 채택할 직접 지역 변화 설명이 부족하므로 상권 아이디어를 억지로 채우지 않는다. 일부 전국 자료도 여러 사건을 묶은 기사나 사진 기사라 깊은 응용 근거로는 약하다.

기존 GPT 검토는 두 지역 모두 5건 전부 generic(응용 구체화 필요)으로 평가했다. 이번에 바꾼 내보내기 단서를 GPT로 재평가하지 않았다. 검토 수행 완료를 아이디어 승인으로 표시하지 않으며 PDF에 응용 보완 건수를 표시한다. 실제 고객 호응이나 성과를 검증한 자료로 해석하지 않는다.

다음 품질 작업은 직접 지역 변화와 구체적인 참여 방식이 있는 행사 사례를 우선 선정하고, 같은 전국 사례에서도 지역 관측이 어떤 기획 질문을 바꾸는지 보강하는 것이다. 상시 서버 배포는 별도 단계다.

## 재현

저장된 검토 결과 번들 두 개를 준비한다. 입력은 request, results, critic와 선택적 quant_evidence를 포함한다. 저장 자료에 인증정보가 없는지 먼저 확인한다.

```sh
PYTHONPATH=. python tools/check_regional_exports.py <동래-번들.json> <광화문-번들.json>
PYTHONPATH=. python -m unittest tests.test_planning_prompt tests.test_report_exports tests.test_pdf_editorial
node tests/test_planning_hints.js
```

Python·PDF 의존성과 한글 글꼴, Node가 필요하다. 도구는 .env를 읽거나 새 조사를 접수하지 않는다. 비교 요약·기획 단서는 output/regional-validation, PDF는 output/pdf/regional-validation에 저장한다. 저장 결과와 생성 파일은 Git에 넣지 않는다.

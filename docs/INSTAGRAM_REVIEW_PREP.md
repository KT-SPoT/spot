# Instagram 해시태그 검색 검수 준비

2026-10-04 확인. 이 문서는 준비 자료이며 검수 제출이나 자동 검색 구현 완료를 뜻하지 않는다.

## 현재 확인한 상태

- 사용자가 Page 목록, 연결된 전문 계정, 자신의 미디어 조회를 확인했다.
- Meta 앱의 Instagram 권한 및 기능 화면에서 `Instagram Public Content Access`는 아직 추가되지 않았다.
- 앱 검수 초안에는 `Marketing API Access Tier`가 보인다. 광고 API 초안은 해시태그 검색 신청을 대신하지 않는다.
- SPoT은 수동 링크·공식 임베드와 서버 토큰으로 지정한 해시태그의 공개 게시물을 조회하는 화면을 제공한다.
  실제 공개 조회 성공은 미검증이다. 사용자 OAuth 연결·토큰 발급/갱신·자동 Scout 수집은 아직 구현되지 않았다.
- 기본 계정 조회 성공은 공개 해시태그 검색 승인이나 타 계정 자료 수집 성공을 뜻하지 않는다.

## 다음 순서

1. 앱의 이용 사례 → Instagram → 권한 및 기능에서 `Instagram Public Content Access`의 설명과 요구사항을 확인한다.
2. 해당 기능을 추가하고 대시보드가 제공하는 테스트/검수 경로를 따른다. 추가 자체가 운영 승인이라는 뜻은 아니다.
3. `instagram_basic`과 필요한 Page 조회 권한만 신청 대상으로 검토한다. 게시·메시지·댓글·광고 관리 권한은 이 검색 기능의 근거로 신청하지 않는다.
4. 실제 로그인 및 검색 화면을 구현한다. 개발 접근 수준으로 가능한 범위와 IPCA 승인 필요 범위를 구분하고, 승인 전 권한 오류를 성공 결과로 대체하지 않는다.
5. 외부에서 접속 가능한 앱, 개인정보처리방침, 데이터 삭제 안내, 검수자 테스트 절차를 준비한다. 사업자 확인 등 추가 요건은 실제 대시보드 안내에 따른다.
6. 구현한 기능만 화면 녹화하고 검수 설명을 작성한다. 로그인→연결 Page/전문 계정 선택→검색→원본 게시물 확인→연결 해제 흐름을 보여준다. 한국어 UI라면 영어 자막을 제공한다.
7. 신청 권한·기능 및 실제 허용 용도가 일치하는지 확인한 뒤 제출한다.

## 제안하는 첫 연결 범위

뉴스에서 발견한 행사명 또는 운영자가 지정한 브랜드/캠페인 해시태그 1개로 공개 게시물을 조회하고,
Trend 사례 아래에 원본 링크·게시 시각·조회 시각·캡션을 표시하는 작은 기능부터 만든다.
조회 결과가 없거나 권한이 부족하면 해당 상태를 명확히 표시한다.

전국의 임의 트렌드를 광범위하게 분석하는 목적이 IPCA 허용 용도와 일치하는지는 별도 확인이 필요하다.
브랜드 캠페인 조회 등 실제 사용 목적에 맞춰 설명하고, 허용 범위에 맞추기 위해 존재하지 않는 기능을 꾸며 쓰지 않는다.
게시물 작성자나 반응자의 나이·성별·지역 선호를 추정하지 않는다. GPT 전달·PDF 근거 편입은 첫 연결 범위에서 제외한다.

## 검수 설명 초안 — 구현 후 사실과 일치하도록 수정

SPoT은 매장 홍보 기획 전 자료를 검토하는 도구입니다. 운영자가 조사 중인 브랜드/캠페인의
해시태그를 지정하면 승인된 Instagram API를 통해 공개 게시물을 조회하고 원본 링크와 게시 시각을
보여주려 합니다. 공개 게시물은 캠페인 관련 콘텐츠를 확인하는 참고 자료이며 고객의 연령·성별,
구매 의향 또는 행사 성과를 입증하는 자료로 사용하지 않습니다. 콘텐츠 게시, 메시지 전송,
댓글 관리 기능은 요청하지 않습니다.

위 내용은 계획이며 아직 구현된 기능에 대한 제출 문구가 아니다. 승인 가능성을 보장하지 않는다.

## 테스트 요청 예시

Graph API Explorer에서 사용자 토큰을 선택한다. 토큰은 요청 경로에 붙이지 않는다.
아래 중괄호는 실제 확인한 ID로 바꾸고 해시태그 앞의 `#`는 제외한다.

```text
ig_hashtag_search?user_id={instagram-user-id}&q={hashtag}
{hashtag-id}/recent_media?user_id={instagram-user-id}&fields=id,caption,permalink
{instagram-user-id}/recently_searched_hashtags?fields=id,name
```

권한 오류가 발생하면 비밀 값 없이 오류 code/message만 기록한다. 공개 해시태그는 전문 계정당
연속 7일에 서로 다른 30개까지다. 같은 해시태그 재조회로 예산이 초기화되지 않는다.
Stories는 지원되지 않으며 타인 게시물의 미디어 URL이 빠질 수 있어 원본 링크를 기본으로 사용한다.
요청 필드는 각 엔드포인트의 현재 지원 목록에 맞춰 조정한다.

## 제출 전 남은 실제 준비물

- 안정적으로 접속 가능한 HTTPS 앱 주소와 로그인 콜백
- 실제 동작하는 연결/검색/오류 표시/연결 해제 화면
- 실제 보관 기간, 삭제 방법, 문의처가 기재된 개인정보 및 삭제 안내
- 검수자가 재현할 수 있는 테스트 절차와 필요한 테스트 계정
- 토큰의 서버 보관, 로그 비밀 값 제거, 만료/갱신 처리
- 7일 해시태그 사용 목록 관리와 호출 제한 처리

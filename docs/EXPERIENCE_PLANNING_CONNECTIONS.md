# 지역 관측과 전국 사례의 기획 연결점

2026-10-06 사용자 요청에 따른 구현. SPoT의 결과는 완성된 행사안이 아니라 조사 근거에서 연결한 기획 질문이다.

브리프 생성 단계에서 검증된 Quant 카드와 출처가 연결된 Trend 사례를 함께 읽는다. 수집 검색어나 Scout 계약은 변경하지 않는다. 기존 `adaptation_hypotheses`의 research_question / mechanism / statement와 `context_source_refs`를 사용하며 새 필수 필드를 추가하지 않는다. 연결한 Quant 출처는 카드의 context_sources에도 보존한다.

## 연결 규칙

- 기사에 나온 촬영·소개/공유, 물건 구매·소장, 직접 사용·시연·비교, 미션 수행·완료 행동을 구분한다. 홍보대사 SNS 활동을 방문객의 참여·호응으로 바꾸지 않는다.
- 행사 분류나 ‘체험’이라는 단어만으로 행동이 확인됐다고 간주하지 않는다. 기존 원문 표현 대조·맥락 진단은 보존하며, 새 규칙이 지원하지 않는 방식에 연결점을 억지로 생성하지 않는다.
- 매출 연령 구성은 대상 연령 기획 후보를 검토할 근거로 사용한다. 특정 세대의 선호·실제 매장 방문 고객 비중을 뜻하지 않는다.
- 유동인구와 매출액의 최다 연령 구간이 다르면 발견을 위한 도입과 기능 비교 접점을 서로 다른 후보로 살펴보는 질문을 제공한다. 두 모집단 사이의 구매 전환을 주장하지 않는다.
- 직장인구가 확보되면 업무 기능 체험이라는 별도 후보를 제공한다. 매출 최다 연령과 합쳐 특정 연령의 직장인 고객을 만들지 않는다. 직장인구 수만으로 직장인이 많은 상권이라고 상대 평가하지 않는다.
- 구성비 동률·0·NaN·자료/출처 누락은 단일 최다 연령 연결을 만들지 않는다. 기준 기간과 범위를 보존하며 기간이 다른 표를 같은 시점으로 합산하지 않는다.
- 출처가 있지만 구체적 행동이 없는 사례는 전국 소식으로 남긴다. 기존 맥락 진단을 보존하되 새 지역 연결 질문은 만들지 않는다.

지역 관측 → 사례에서 참고할 행동 → 연결 단서를 한 문장 흐름으로 제공한다. 사례당 최대 네 질문이다. 웹 Trend 상세 화면, 흥부장 여섯 항목, 텍스트 및 PDF가 같은 문장을 사용한다. 관련 원본 출처는 연결하되 같은 Quant 출처를 쓰는 모든 통계 제목을 근거 목록에 나열하지 않는다.

## Critic

연결 질문 자체의 유용성을 평가한다. supplied observation이 어떤 기획 질문을 바꾸는지, 보도 행동에서 크게 벗어나지 않았는지, 모집단·선호·인과관계를 과장했는지 검사한다.

호응 자료·인터뷰·인과 증명·완성된 차별화 행사안을 useful의 필수 조건으로 요구하지 않는다. 관측에 연결된 탐색 질문은 contextual로 평가할 수 있으며 단순 지역명 치환·수치 나열만으로 useful로 통과시키지 않는다. useful과 평가 차원의 일치 검사는 유지한다. 소비자 반응이나 사실 인증을 수행하는 것은 아니다.

관련 매출 연령 구성비를 Critic 입력에 포함한다. 무관한 화면 전용 그래프나 원본 API 보고서는 보내지 않는다. 이번 구현 검사는 기존 동래·광화문 자료의 재생과 모의 평가 응답으로 수행했으며 새 GPT 평가는 실행하지 않았다. 기존 저장 평가의 generic 판정이 새로운 질문에 대한 판정은 아니다. 새 조사부터 수정된 입력·평가 지침이 적용된다.

## 검증

동일한 촬영 사례에서 매출 60대 이상인 입력과 매출 20대·유동 60대 이상인 입력의 질문이 달라지는지 검사한다. 직장인구/매출 연령의 교차 집단을 만들지 않는지, 홍보자/방문객 구분, 빈 자료·동률·비정상 구성비, 기사에 행동이 없는 경우도 검사한다.

전체 Python 241개와 웹 기획 단서·Trend 보드 검사가 통과했다. 동래·광화문의 웹/텍스트/PDF 일치는 기존 저장 자료로 확인했다. 수집된 사례 중 일부가 여전히 짧은 기사·묶음 기사여서 기획 질문의 다양성을 제한한다. 이번 변경은 검색 품질 전체나 실제 고객 호응을 검증한 결과가 아니다.

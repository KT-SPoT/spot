# 전국 Trend 실제 검색 검증 — 2026-10-02

## 실행 범위

입력은 기존 명지국제신도시 점포 / Galaxy Z Fold8 요청을 사용하고 조사 기준일을
2026-10-02로 갱신했다. Quant·Local은 저장된 실제 실행 자료를 재생했고,
Trend만 네이버 뉴스 API로 새로 검색했다. 모든 모듈을 당일 재수집한 결과는 아니다.
YouTube는 기존 quota 문제를 보류하기 위해 이번 검증에서 제외했고, GPT 호출은 0회다.
네이버 설정과 키 값은 문서·출력·Git에 포함하지 않았다.

첫 실행은 3개 검색어 / HTTP 요청 8회였다. 연령대가 들어간 음식·축제 검색어로
탐색 폭이 좁아지고, 참여 방식인 미니게임을 업종으로 오인하며, 관련 보도가 참고
슬롯을 반복 차지하는 문제를 확인했다. 이후 연령대 필터를 제거한 3개 검색어로
한 번 더 검색했고, HTTP 요청 6회로 600개 검색 행 / 고유 URL 573개를 받았다.
이후 수정 검증에는 저장된 응답만 재사용해 추가 검색을 하지 않았다.

## 적용한 보완

- 검색어: `게임 팝업 체험`, `음식 팝업 체험`, `지역 축제 체험`.
- Quant 성별·연령은 후보 선정과 조사 가설의 맥락으로 유지한다. 검색어에 그 연령이
  있어야 한다는 조건이나 성별별 업종 배정은 사용하지 않는다.
- 제목의 업종과 참여 방식은 분리한다. 화장품 팝업의 미니게임은 게임 참여 구조이며,
  그 팝업을 게임 업종이라고 분류하지 않는다.
- 제공자별 10자료 제한 전에 업종 다양성과 관련 보도 묶음 대표를 고려한다.
- 참고 슬롯 최대 5개는 관련 보도 묶음별로 사용한다. 동일 날짜·지역·고유명 표현을
  공유할 때만 보수적으로 묶으며, 관련 출처는 Brief에 보존한다. 독립 행사 확정은 아니다.
- 참여 의사·설문 자료는 유용한 고객층 조사 맥락으로 별도 표시하고 실제 행사·반복
  체험 패턴의 증거 수에 포함하지 않는다.

## 최종 출력과 활용 검토

선정된 검색 후보자료 10건에서 축제·뷰티·문화·음식·게임 분야의 참고 슬롯 5개를
구성했다. 검색 메타데이터 기반 후보 상태 `partial`을 유지한다. 일부 업종 분류는
제목 표현에 따른 추정이며, 참고 점수는 인기·매출·고객 선호를 나타내지 않는다.

Sweet Agent의 미션·스탬프 구조는 [기사 원문](https://game.donga.com/124463/)을 읽어
검색 요약과 대조했다. 해당 보도는 개최 계획을 포함하며, 현장 운영·참여 실적의
검증을 뜻하지 않는다. 노브랜드 버거 사례 역시 [기사 원문](https://www.cstimes.com/news/articleView.html?idxno=722540)의
참여 방식 설명과 대조했다. 이 두 건의 수동 원문 대조는 모든 후보의 자동 검증이나
Scout의 `verification_status` 승격이 아니다. 나머지는 검색 요약만 확인한 후보다.

저장된 소상공인365 자료에서 유동인구 주요 연령은 40대, 매출 비중 주요 연령은
60대 이상이다. 서로 다른 모집단이므로 하나의 확정 행사 고객층으로 합치지 않는다.
공공 관측값은 정량 기준으로 사용하지만, 특정 연령·성별이 위 사례에 크게 호응했다는
참여자·선호 자료는 이번 수집으로 확보하지 못했다. 다양한 안내 방식과 참여 시간의
적합성을 조사할 수 있으며, 연령만으로 기기 사용 능력을 단정하지 않는다.

## 검증과 한계

다양성, 관련 보도 출처 보존, 서로 다른 날짜의 행사 분리, 설문 맥락 분리를 확인한다.
실제 API 응답 재생도 공통 계약과 Brief 생성 경로를 통과했다.

않는다. 네이버 제공일과 행사 개최일은 다르다. 실제 호응·고객 구성·방문 증가·매출
효과·대상 기기의 지원 기능은 확인되지 않았다. 현재 매장 응용 출력은 규칙 기반
조사 질문이며 상세 운영안이나 AI 검증 완료 결과가 아니다.

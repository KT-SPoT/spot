# Trend 리서치 보드와 내보내기

## PDF 보고서

완료된 브리프의 PDF 다운로드는 6개 장으로 구성한다: 지역 요약·주요 지표, 상권과 고객 구성,
지역 변화·생활권 맥락, 전국 행사 참고, 기획 연결점·확인 사항, 출처·탐색 범위.
첫 페이지에 주요 지표를 모으고 그래프는 0~100% 공통 눈금으로 표시한다. 0%도 보존하며
성별·연령·매출·인구의 모집단을 같은 것으로 해석하지 않는다. 긴 Local 설명·Trend 응용 질문은
읽기 쉬운 길이로 요약 표시하고 전체 원문 브리프는 MD로 내려받는다. 참고 사례의 호응·성과는 미확인으로 표시한다.
원본 출처는 번호와 클릭 가능한 링크를 제공한다. 내보내기는 새 Scout·GPT 호출을 발생시키지 않는다.

뉴스 본문은 보도된 내용·참고할 이유·매장 활용 힌트(기획 제안)를 분리한다.
Local은 기사 제목이 아닌 근거 문장에서 이동·주거·시설 연결점을 찾고 주제별 대표 보도를
우선 표시한다. 같은 주제의 추가 기사와 역사·행정 배경은 부록에 보존한다. Trend는 실제 보도
표현과 기존 브리프 응용 방식이 함께 뒷받침하는 사례만 본문에 표시하며 복합 뉴스 모음은
추가 자료로 분리한다. 이는 표시용 규칙이며 GPT의 새 사실 검증이나 행사 효과 판정이 아니다.
기사별 반복 경고는 마지막 활용 범위에 모으고 보도 날짜·협약 단계·통계 기준월은 유지한다.

## 흥부장용 기획 프롬프트

기존 다운로드 버튼은 완료된 브리프를 기획 입력으로 정리한다. 공공기관 관측은 기간·집계 범위·
출처와 함께 전달하고, Local·Trend는 PDF와 동일한 선별·해석 구조를 사용한다. 연결점이 약한
자료는 별도 배경 목록에 보존한다. 원문 전체를 반복해서 붙이지 않으며 전체 기록은 MD로 제공한다.
최종 다운로드는 흥부장의 지정 순서(상권 → 타깃 고객 → 타깃 상품 → 행사 기간 → 직원 수 →
판촉물·예산)에 맞춘 입력 문안이다. 사람이 읽고 채우기 쉽도록 각 항목을 줄바꿈하고,
지역·체험 참고, 판촉물 힌트, 숨은 기회, 활용 안내를 별도 문단으로 구분한다.
유동인구·매출의 고객 구성 관측을 우선 활용하되 매장 방문객 비중으로
단정하지 않는다. 실제 보도 표현과 기존 응용 방식이 연결되는 판촉물 후보·숨은 기회 가설을
덧붙인다. 제품·시기·예산·인력·보유품 등은 사용자가 입력하기 전까지 편집 가능한 자리로 남긴다.
판촉물 후보는 실제 보유품과 구분한다. 상세 근거 정리 함수는 유지하며 원본 PDF·MD와 함께 검토할 수 있다.
프롬프트 생성은 기존 자료만 사용하며 GPT를 호출하거나 다른 서비스로 자동 전송하지 않는다.

## 이번 구현

매장 중심 신규 Trend 조사 검색 3개는 업종 미지정 `팝업`, `오프라인 체험 행사`,
자료 기준월의 축제 검색이다. 성별·연령에서 게임·음식 같은 취향을 추정하지 않는다.
`query_context.search_plan`에 검색어와 이유를 보관하고 HTTP 결과의 선택 메타데이터
`trend_discovery`로 화면에 전달한다. 과거 결과는 검색 기록 미확보로 표시한다.

참여 방식 7개 분류는 유지한다. 이는 수집 표현을 묶는 분류표이며 결과를 7개로 채우거나
시장 추세를 인증하는 목록이 아니다. 실제 입력·검색 자료에 따라 행사 사례가 달라진다.
전시·공연·박람회·문화제·마라톤도 오프라인 행사 후보에 포함한다.

화면은 독립적인 전국 참고 영상 목록 → 대표 사례 선택 → 해당 사례의 뉴스·체험 방식·매장 연결점·확인할 점으로
구성한다. 뉴스 옆에 무관한 영상을 배치하지 않으며, 사례 탭 변경은
영상 선택·재생에 영향을 주지 않는다. 긴 응용 질문·고객 맥락·검색 과정과 Instagram 추가 기능은 펼쳐 읽는다.
`trend_discovery.video_sources`에 수집한 영상 출처를 최대 10개 보존해 브리프 미채택으로
영상이 화면에서 사라지지 않게 한다. 연결된 출처 영상과 별도로 수집한 참고 영상은 구분한다.
같은 행사라는 인증은 아니며, 참고 영상은 브리프 근거 수에 추가하지 않는다.
썸네일 클릭 후에만 플레이어를 불러오고 원본 링크는 항상 제공한다.
리서치 개요에도 대표 영상 섹션을 표시한다. 이전 결과에 영상 출처가 없으면 표시하지 않는다.
Local 기사 썸네일과 기존 근거창·출처 탭은 유지한다.

Instagram 링크는 공개 게시물/릴스만 허용하고 탭·요청·사례별로 저장한다.
공식 임베드는 미리보기 버튼을 누른 뒤 로드한다. 조사 자료와 분리된 표시용이며
GPT·근거 수·내보내기에는 추가되지 않는다. [자동 API 연결 안내](INSTAGRAM_SETUP.md).

## 브리프 내보내기

- PDF: 완료된 브리프의 지역 요약·공공 관측 지표·분포 막대·지역 변화·행사 참고·확인 사항·클릭 가능한 출처.
- 흥부장 작성 힌트: 상권·타깃 고객·타깃 상품·행사 기간·직원 수·판촉물/예산의 여섯 항목별 조사 참고, 선택 힌트, 사용자가 결정할 질문.
  브리프 화면에서 항목별 근거 확인과 복사, 전체 텍스트 다운로드가 가능하다. 완성된 기획 프롬프트를 생성하지 않는다.
  예산·인력·일정·상품은 사용자 결정이며, 판촉물 후보는 보유품·효과와 구분한다. GPT 추가 호출이나 외부 자동 전송은 없다.
- 원문 MD: 기존 전체 Markdown 저장.

PDF의 확인 사항은 처음 12개, 행사 응용 질문은 사례당 처음 3개를 요약한다.
전체 Critic 항목·원문 근거 상세는 원문 MD에 보존한다. 임의 수치·증감률을 만들지 않는다.
한글 글꼴은 Windows Malgun 또는 Linux Nanum을 사용한다. 글꼴 미설치 시 PDF만 오류를 표시한다.
다운로드는 해당 작업을 접수한 세션에서만 가능하다. 완료 캐시가 있으면 n8n 조회 없이
생성한다. 없으면 상태 GET을 한 번 수행하며 새 Scout/GPT 조사를 접수하지 않는다.

## 아직 별도 구현인 부분

공식 제품 기능·제품군 고객 조사, 질문별 응답 문서, 수능 등 전국 일정 캘린더의
공식 정보 수집은 이번 검색어 변경으로 완료된 기능이 아니다. 기준월 축제 검색과
검증된 전국 일정 데이터는 다르다. 인스타그램 App Review·실토큰 수집도 미연결이다.

상시 서버는 [배포 준비 안내](HOSTING_SETUP.md)를 따른다. Docker/TLS 실배포,
영구 작업 저장·개인별 로그인은 아직 검증/구현되지 않았다.

전체 오프라인 Python 및 Node 검사와 실제 저장 자료 PDF의 페이지 렌더링을 로컬에서 확인한다.
기존 CI 설치 목록에 PDF 의존성을 포함했다. 한글 글꼴이 없는 검사 환경에서는
PDF 본문 렌더링 테스트 1개만 건너뛰며, 세션 소유권·캐시·접수 비호출 검사는 계속 실행한다.
한글 PDF 시각 검증은 Malgun/Nanum 글꼴을 갖춘 환경에서 수행해야 한다.

작성 힌트 화면·다운로드는 브라우저에 도착한 완료 브리프에서 생성하며 새 접수·조회 없이 동작한다.
기존 `/handoff` 내보내기 주소도 같은 여섯 항목의 작성 힌트 텍스트를 반환한다. Scout/Brief 공통 스키마는 변경하지 않는다.
유동·주거·직장·매출 집계의 기준월과 범위를 함께 표시한다. 피크 시간은 행사 소요 시간이 아니며
연령·성별 구성은 실제 방문 고객·상품 선호나 교차 비율이 아니다.

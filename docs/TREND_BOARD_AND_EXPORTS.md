# Trend 리서치 보드와 내보내기

## 이번 구현

매장 중심 신규 Trend 조사 검색 3개는 업종 미지정 `팝업`, `오프라인 체험 행사`,
자료 기준월의 축제 검색이다. 성별·연령에서 게임·음식 같은 취향을 추정하지 않는다.
`query_context.search_plan`에 검색어와 이유를 보관하고 HTTP 결과의 선택 메타데이터
`trend_discovery`로 화면에 전달한다. 과거 결과는 검색 기록 미확보로 표시한다.

참여 방식 7개 분류는 유지한다. 이는 수집 표현을 묶는 분류표이며 결과를 7개로 채우거나
시장 추세를 인증하는 목록이 아니다. 실제 입력·검색 자료에 따라 행사 사례가 달라진다.
전시·공연·박람회·문화제·마라톤도 오프라인 행사 후보에 포함한다.

화면은 대표 사례 선택 → 해당 사례의 뉴스·체험 방식·매장 연결점·확인할 점 → 독립적인
전국 참고 영상 목록으로 구성한다. 뉴스 옆에 무관한 영상을 배치하지 않으며, 사례 탭 변경은
영상 선택·재생에 영향을 주지 않는다. 긴 응용 질문·고객 맥락·검색 과정과 Instagram 추가 기능은 펼쳐 읽는다.
`trend_discovery.video_sources`에 수집한 영상 출처를 최대 10개 보존해 브리프 미채택으로
영상이 화면에서 사라지지 않게 한다. 연결된 출처 영상과 별도로 수집한 참고 영상은 구분한다.
같은 행사라는 인증은 아니며, 참고 영상은 브리프 근거 수에 추가하지 않는다.
썸네일 클릭 후에만 플레이어를 불러오고 원본 링크는 항상 제공한다.
리서치 개요에도 대표 영상 섹션을 표시한다. 이전 결과에 영상 출처가 없으면 표시하지 않는다.
Local 기사 썸네일과 기존 근거창·출처 탭은 유지한다.

Instagram 링크는 공개 게시물/릴스만 허용하고 탭·요청·사례별로 저장한다.
공식 임베드는 미리보기 버튼을 누른 뒤 로드한다. 조사 자료와 분리된 표시용이며
GPT·근거 수·내보내기에는 추가되지 않는다. [자동 API 연결 안내](INSTAGRAM_SETUP.md).

## 브리프 내보내기

- PDF: 완료된 브리프의 지역 요약·공공 관측 지표·분포 막대·지역 변화·행사 참고·확인 사항·클릭 가능한 출처.
- 흥부장 프롬프트: 접수한 매장과 전체 Markdown 브리프를 담은 편집 가능한 텍스트.
  운영 시기·예산·인력은 사용자가 채운다. GPT 추가 호출이나 외부 자동 전송은 없다.
- 원문 MD: 기존 전체 Markdown 저장.

PDF의 확인 사항은 처음 12개, 행사 응용 질문은 사례당 처음 3개를 요약한다.
전체 Critic 항목·원문 근거 상세는 MD/흥부장 프롬프트에 보존한다. 임의 수치·증감률을 만들지 않는다.
한글 글꼴은 Windows Malgun 또는 Linux Nanum을 사용한다. 글꼴 미설치 시 PDF만 오류를 표시한다.
다운로드는 해당 작업을 접수한 세션에서만 가능하다. 완료 캐시가 있으면 n8n 조회 없이
생성한다. 없으면 상태 GET을 한 번 수행하며 새 Scout/GPT 조사를 접수하지 않는다.

## 아직 별도 구현인 부분

공식 제품 기능·제품군 고객 조사, 질문별 응답 문서, 수능 등 전국 일정 캘린더의
공식 정보 수집은 이번 검색어 변경으로 완료된 기능이 아니다. 기준월 축제 검색과
검증된 전국 일정 데이터는 다르다. 인스타그램 App Review·실토큰 수집도 미연결이다.

상시 서버는 [배포 준비 안내](HOSTING_SETUP.md)를 따른다. Docker/TLS 실배포,
영구 작업 저장·개인별 로그인은 아직 검증/구현되지 않았다.

전체 오프라인 Python 및 Node 검사와 실제 저장 자료 PDF의 페이지 렌더링을 로컬에서 확인한다.
기존 CI 설치 목록에 PDF 의존성을 포함했다. 한글 글꼴이 없는 검사 환경에서는
PDF 본문 렌더링 테스트 1개만 건너뛰며, 세션 소유권·캐시·접수 비호출 검사는 계속 실행한다.
한글 PDF 시각 검증은 Malgun/Nanum 글꼴을 갖춘 환경에서 수행해야 한다.

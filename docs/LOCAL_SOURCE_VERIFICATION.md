# Local 원문 대조

Local은 검색 후보 최대 15개의 원문을 실행 중 읽고, 자동 대조 결과를 출처의 `verification`에 기록한다.
기존 `SpotRequest` / `ScoutResult` 공통 필드는 유지한다. 유튜브 호출·캐시·할당량은 이 변경 범위에 포함하지 않는다.

## 판단과 출력

- 엄격한 직접 대조는 요청 지역명과 변화 표현이 같은 원문 문장에 있어야 한다. 이 조건에 맞지 않아도 아래 문맥 분류로 활용 가능성을 검토한다. 제목·메뉴·관련 기사·사이드바의 지역명만으로 통과시키지 않는다.
- 원문 `article:published_time`, `datePublished` 등에서 게시일을 확인하고 입력 기간과 비교한다. 원문 게시일이 오래되면 최근 검색 제공일이 있어도 제외한다. 원문 날짜가 충돌하면 미확인으로 남긴다.
- `text_corroborated`: 본문 영역 또는 구조화된 기사 본문, 원문 게시일, 지역·변화 문장을 함께 대조한 자료. 실제 사건 발생과 반경 관련성의 검증은 아니다.
- `candidate`: 문장은 있지만 원문 게시일 또는 확실한 본문 영역을 확보하지 못한 자료.
- `context_corroborated`: 원문에서 관련 문맥을 찾은 자료. 직접 사업 연결·같은 행정구역 맥락·배경으로 역할을 표시한다. 엄격한 문장·게시일 대조와 같은 등급이 아니며 원문 날짜가 없으면 뉴스 제공일과 그 한계를 표시한다.
- `unconfirmed`: 요청 지역의 구체적 변화 문장을 대조하지 못한 자료. 다른 동네 변화·과거 입주 비교·단계가 불명확한 일반 설명도 포함한다.
- `unavailable`: 접근 차단·시간 초과·비HTML 등으로 원문을 읽지 못한 자료.
- `rejected`: 원문 게시일이 조사 기간 밖인 자료. 결과의 출처·insights에서 제외하고 `query_context.verification_log`에 남긴다.

최근 기사 안의 과거 사례는 최근 변화로 올리지 않지만 `background`로 활용할 수 있다. 다른 신도시·동의 변화는 요청 지역의 변화로 올리지 않고 `surrounding_context`로 활용할 수 있다. 이 분류는 같은 행정구역 문맥이며 지리적 인접성·실제 생활권을 확인한 것은 아니다.
직접 사업 문맥은 원문에 요청 지역명이 있고 같은 지역명 어간의 지구·공원 표현이 연결되는 경우를 포함한다. 이는 규칙 기반 연결 후보이며 행정 경계·동명 지역·지시어·문장 의미 전체를 검증하지 않는다.
계획·목표·예정·조건 표현은 개관·준공 표현이 함께 있어도 `scheduled`로 표시한다. 개관했다는 과거형 문장은 `reported_opening`처럼 **보도 내용**으로만 표시한다. 부인·루머 표현은 완료로 처리하지 않는다.
둘 이상의 대조 문장에서 단계가 다르면 `unverified`로 남긴다. 이는 규칙 기반의 보수적 대조이며 문장 의미·지시어·사업 단계 전체를 해석하는 검증은 아니다.

같은 역할·지역·변화 문장 지문과 단계, 7일 이내 날짜인 보도는 한 insight의 `source_ids`로 묶는다. 요청 지역명이 등장하는 원문에서 같은 지역 지구의 동일 차수 실시계획을 다루는 경우도 묶고, 각 보도의 발췌와 단계·날짜를 `supporting_facets`로 남긴다. 원문 날짜가 없으면 뉴스 제공일로 묶으며 그 한계를 표시한다. 이는 중복 보도 후보 묶음이고 독립 사건 수의 최종 확정은 아니다.
원문 전체는 저장하지 않으며 출처에 120자 이내 발췌·대조 시각·추출 방식·게시일·실패 사유와 문장 해시를 남긴다.

## 브리프

`direct_change`는 `local_changes`에, `surrounding_context`와 `background`는 기존 `unique_local_signals`의 Local 근거 카드로 저장한다. 브리프는 직접 변화·주변 행정구역 맥락·배경 자료를 별도 구역으로 표시하며 직접 변화 건수에는 보조 자료를 포함하지 않는다. 새로운 Brief 최상위 필드를 추가하지 않는다.
`text_corroborated`와 `context_corroborated`를 등급과 한계를 표시해 인용한다. `unconfirmed`, `unavailable`은 원래 Scout 결과와 수동 확인 항목에 남긴다. 출처가 연결되지 않는 자료는 요약하지 않는다.
계획을 현재 운영으로 표시하지 않고, 원문 보도 대조와 실제 사건 검증을 구분한다. 근거가 적어도 고정 사례를 보충하지 않는다.

## 실행과 제한

기존 `--mode live` 통합 실행에서 자동 적용된다. 별도 키나 패키지는 필요 없다.
`--mode offline`에서는 원문도 호출하지 않는다. 공개 HTTP(S) 기사만 읽으며 초기 URL과 리다이렉트의 공용 주소 여부를 검사한다. 키 형태의 쿼리·계정정보·비표준 포트를 거부한다.
URL당 읽기 제한은 1.5MB, 네트워크 timeout은 8초, 리다이렉트는 최대 3회다. 비HTML·로그인·자바스크립트 렌더링 페이지는 지원하지 않는다.
여러 단계의 네트워크 요청·DNS를 포함한 전체 실행 시간 제한은 별도로 구현하지 않았다.
기사 구조·지역 약칭·문장 표현에 따라 적격 자료도 누락될 수 있다. 게시일은 행사일과 다르므로 실제 변화 시점과 행정 경계·거리·기관 원출처는 추가 검토해야 한다.
